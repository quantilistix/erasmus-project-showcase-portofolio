This is a conventional layered neural network writen in Lua and Love2D. It learns through backpropagation, though I didn't implement the chain rule and it basically run the network for each weight and bias twice to calculate the derivatives. Unfortunately, I don't have a training dataset, so I trained it on a noise pattern to produce an output. It successfully learnt as only one neuron is lit in the output layer. It also saves the neural network in a custom file format. I don't recall whether the saving works or not.
