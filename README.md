# Introduction #

This git repo contains several personal projects of mine I've writen when I was a kid. Among these are 2 of my most recent projects. These projects are separated into 2 categories: hand-coded and vibe-coded. The hand-coded projects are projects I wrote by my hand a long time ago without the use of AI or moderate use of it for debugging in AI's early stages. The usage of AI is clarified in the README.md files, though you have to take my word for it. The vibe-coded projects are projects I wrote with heavy use of AI, in some cases, only with AI. Some projects are proofs of concepts, others unfinished projects that I quit, projects I am still working on and fillers :)

I do not guarantee the absence of profanity in all programs' code.

# Building and Running #

Each project has a README.md file that contains a summary of the project among a BUILDNRUN.md file that contains the instructions on how to build and run the program or install the required software to build and run them. Since I made these projects on one computer and I made the build system on the edge of working, I asked ChatGPT to make the build systems for all projects able to run on all devices and write the BUILDNRUN.md files. I didn't consider the build systems to be a part of the programs as of the code itself, however, the README.md files are writen by me by hand. If the build and run instructions don't work for you, feel free to use AI to figure it out. I don't have many computers to test each program on, but they should be cross-platform in theory.
