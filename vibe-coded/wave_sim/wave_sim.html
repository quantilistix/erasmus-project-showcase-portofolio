View: X: 0, Y: 0 | Use arrow keys or nav buttons to move around
Wave Mode: Click/drag to create wave sources (negative values create inverse waves)
Wall Mode: Click/drag to place walls that reflect waves
Emitter Mode: Click/drag to place emitters with current frequency & amplitude
Receiver Mode: Click/drag to place receivers that detect specific frequencies
Controls: Arrow keys to navigate, +/- to zoom, brush size for painting area
Receivers: Dark when inactive, bright when detecting their target frequency
Wall Absorption: Each wall stores its absorption value (0.0-1.0)
Dark walls = reflective, bright walls = absorptive
Physics: Each cell has displacement, velocity, and acceleration.
Acceleration = (sum of neighbor displacements - 4×center) × wave_speed²
Velocity += acceleration, Position += velocity × damping
Walls can reflect (absorption=0) or absorb (absorption=1) waves.
Receivers: Use DFT analysis on last N frames to detect target frequencies.
